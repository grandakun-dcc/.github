# Grandakun DCC

Maintained MCP servers and workflow extensions for digital content creation tools.

## Repositories

- `maya-mcp` — public Fork of GG Maya MCP, used as the general Maya base.
- `maya-tools-xiaota` — private Maya production tools and MCP extension.
- `zbrush-mcp` — private ZBrush MCP server using a local bridge plugin.
- `substance-painter-mcp` — public upstream-tracking Fork.
- `marmoset-mcp` — public upstream-tracking Fork.

Validated versions and compatibility information are maintained in the private
`dcc-mcp-catalog` repository.
